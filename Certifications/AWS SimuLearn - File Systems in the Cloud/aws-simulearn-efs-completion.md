## What I Learned

The **File Systems in the Cloud** SimuLearn module provided a guided, scenario-driven simulation environment to develop hands-on skills with AWS cloud-based storage and file system services. Key areas covered included:

- **Amazon EFS (Elastic File System):** Creating and configuring scalable, shared file systems for use with Amazon EC2 instances.
- **Amazon FSx:** Understanding managed file system options including FSx for Windows File Server and FSx for Lustre.
- **Amazon S3 as Object Storage:** Differentiating between object storage and traditional file systems, and understanding appropriate use cases.
- **Mount Targets & VPC Configuration:** Setting up mount targets within a VPC to enable EC2 instances to access shared file systems.
- **Performance & Storage Classes:** Selecting the right storage class and throughput mode based on workload requirements.
- **Security & Access Control:** Applying IAM policies, security groups, and encryption settings to protect cloud file systems.

## Skills Demonstrated

- Provisioning and configuring cloud-native file systems on AWS
- Connecting compute resources to shared file system endpoints
- Applying best practices for performance, availability, and cost optimisation
- Navigating and utilising the AWS Management Console in a simulated environment
