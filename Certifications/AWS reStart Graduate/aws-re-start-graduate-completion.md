## What I Learned

The **AWS re/Start** program is an intensive, scenario-based skills development and training initiative designed to prepare individuals for careers in cloud computing. Key technical and professional areas covered include:

* **Cloud Architecture & AWS Services:** Deep dive into core AWS services across compute (EC2, Lambda), storage (S3, EBS), databases (RDS, DynamoDB), and networking (VPC, Subnets, Route 53).
* **Linux Fundamentals & Bash Scripting:** Operating system navigation, file permissions, shell scripting, process management, and automated administration in Linux environments.
* **Networking & Cloud Infrastructure:** Subnetting, IP routing, DNS configuration, OSI model fundamentals, and secure hybrid cloud connectivity.
* **Security & IAM Management:** Implementing the AWS Shared Responsibility Model, least-privilege IAM policies, multi-factor authentication, and encryption standards.
* **Databases & Scripting (Python & SQL):** Writing relational queries, database design, basic scripting in Python to interact with AWS SDKs (Boto3), and automating operational workflows.
* **DevOps & Infrastructure Automation:** Basic introduction to continuous integration, infrastructure as code concepts, monitoring with Amazon CloudWatch, and automation best practices.
