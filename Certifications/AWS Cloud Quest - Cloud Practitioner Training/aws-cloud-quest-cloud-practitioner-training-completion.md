## What I Learned

**AWS Cloud Quest: Cloud Practitioner** provides a gamified, hands-on learning environment where participants solve real-world technical challenges for virtual city clients using live AWS services. Key technical domains covered include:

* **Cloud Concepts & Global Infrastructure:** Navigating AWS Regions, Availability Zones, Edge Locations, and shared responsibility architecture.
* **Core Compute & Serverless:** Deploying, configuring, and scaling compute solutions using Amazon EC2, AWS Lambda, and Elastic Load Balancing.
* **Storage & Databases:** Hands-on provisioning of Amazon S3, Amazon EBS, Amazon DynamoDB, and Amazon RDS across various workload profiles.
* **Networking & Content Delivery:** Configuring Virtual Private Clouds (VPCs), subnets, routing tables, and internet gateways to isolate and route cloud traffic securely.
* **Security, Identity, & Governance:** Implementing Identity and Access Management (IAM) policies, roles, Multi-Factor Authentication (MFA), and AWS security groups.
* **Billing, Pricing, & Monitoring:** Leveraging AWS Cost Explorer, AWS Budgets, and Amazon CloudWatch to track resource metrics and optimize operational spend.

## Skills Demonstrated
